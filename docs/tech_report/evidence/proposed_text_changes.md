### 1.6 复现入口与证据包

本作品的全部数值分两级举证，均随提交件提供，不依赖任何内部工程记录：

1. **仓库**（源码、COE、串口原始日志、PYNQ 发布包）：
   `https://github.com/HChenZ/amd_fpga_2026`。文中所有 RTL、固件与脚本均可检视，

2. **证据包**（`sha256sums.txt` + 工件）：位流、Vivado 原生报告、串口捕获与 host 侧 JSON。
   解包后在包根执行 `sha256sum -c sha256sums.txt`，全部工件当场校验；
   正文每个数值标注对应的附录 C 条目，附录 C 给出该工件的**工具版本行与数值行原文**。

两级的边界是明确的：仓库负责「怎么做的」，证据包负责「跑出了什么」。
凡二者皆不覆盖者（如策略扫掠的历史过程、未保留的回归报告），正文只作方法叙述或
给出可复跑命令，不作可核验结论。
