# 当前项目简介（提交候选）

本作品面向嵌入式数据安全场景，基于 AMD Zynq-7000（XC7Z020）平台，实现集成轻量级密码加速的
RISC-V 处理器 SoC。处理器采用五级流水线，支持 RV32IM、Zicsr，集成分支预测、指令与数据 Cache、
AXI 互连及 UART、GPIO、CLINT 等外设，配置工作频率为 100 MHz。围绕 NIST SP 800-232 Final
Ascon-AEAD128，提供纯软件、MMIO 硬件加速与定制指令三种方案，并完成分层仿真、官方向量验证与实板演示。

当前 PYNQ 发布版已实现 PS/PL 通信、Python API 和 Jupyter 交互，明文与关联数据各不超过16字节，
三模式各通过289组容量内官方KAT及错误Tag拒绝。固定16字节、AD为空、预热后30次采样的加密中位周期为
软件23342、MMIO1439、ISE3995，对软件周期加速比分别为16.22倍、5.84倍；PS调用墙钟单独记录。
当前实现 WNS +0.034 ns、TNS 0、DRC 0 Error/0 Critical Warning，普通警告保留。

另实现独立的256路RO-PUF与Device DNA密钥通路原型，最新有效板级日志记录同次上电注册质量128/128、
重建状态自检通过；该原型与PYNQ演示版分开，不将其表述为已验证的跨上电可靠密钥或完整安全启动。
项目于11月1日提交并冻结，后续按需完善稳定性、工程通用性和扩展验证。
