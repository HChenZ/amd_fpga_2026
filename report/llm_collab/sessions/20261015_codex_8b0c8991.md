The **vivado-mcp** server provides the following tools for FPGA development:

## Session Management
- `vivado_start` - Launch a new Vivado session (TCL or GUI mode)
- `vivado_stop` - Stop a Vivado session
- `vivado_connect` - Connect to an existing Vivado instance
- `vivado_list_sessions` - List all active Vivado sessions with metadata
- `vivado_cleanup` - Clean up stale sessions and manage connection issues

## Command Execution & Status
- `vivado_execute` - Execute TCL commands in Vivado (supports proxy/webserver modes)
- `vivado_status` - Check session status, command progress, run progress, and diagnose issues
- `vivado_history` - Get or search command history for a session

## Logging & Diagnostics
- `vivado_log_messages` - Parse Vivado log for ERROR, CRITICAL WARNING, WARNING, INFO messages
- `vivado_client_info` - Get information about the connected MCP client and capabilities

## Task Management
- `vivado_todos` - Track progress for multi-step Vivado workflows (plan/update/read/clear/show)

These tools enable complete control over Vivado through TCL commands, support both local and remote (LSF/SSH) deployments, handle GUI and TCL modes, provide session persistence, command history tracking, and structured error reporting.

The server automatically handles:
- Smart proxy for stdin-based command execution
- Long-running command handoffs (synthesis, place & route, bitstream generation)
- OOC (out-of-context) IP synthesis progress tracking
- VNC display management for GUI sessions
- Session recovery and reconnection
