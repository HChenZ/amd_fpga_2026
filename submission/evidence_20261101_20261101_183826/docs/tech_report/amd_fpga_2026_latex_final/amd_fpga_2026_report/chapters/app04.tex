\section{设计准则与证据分级}

接口先于实现；未测量项不填零、不计为通过。分别记录 hardware\_measured、simulation、 implementation\_report 与 not\_measured。正 WNS 只说明该 run 在给定约束下通过，不等于最大频率或跨温压稳定性。相同模块源文件不等于共享一个硬件实例；全 SoC 资源不充作某一加速通路的独立面积。

当前 PUF3 的 bit/hwh/固件由 candidate/manifest 与逐文件哈希对应。打包 source\_commit、实现 context source\_head 和板测工件身份分别记录；板测 JSON 未保存 Git HEAD，不补填其他版本的提交。构建 source\_dirty=true，须结合 source\_sha256、excluded\_from\_build 与构建输入，不能只 checkout 单个 commit 即宣称可复现。
