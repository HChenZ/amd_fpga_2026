\subsection{定制指令编码}

主操作码 custom-0=0x0B、funct7=0；funct3=0/1/2/3 分别为 ascon.w/ascon.rd/ascon.p12/ascon.p8。状态共 10 个 32-bit 字，按 s0 低/高至 s4 低/高排列；非法索引读零、写忽略。索引取自寄存器值而非寄存器编号；具体接口与取消边界见 §2.3.3.4，不声称完整非法编码空间已验收。

\subsection{MMIO 加速器寄存器}\label{mmio-ux52a0ux901fux5668ux5bc4ux5b58ux5668}

当前寄存器为 CTRL(0x00)、STATUS(0x04)、ADLEN(0x08)、MLEN(0x0C)、KEY(0x10--1C)、 NONCE(0x20--2C)、TAGIN(0x30--3C)、AD\_WDATA(0x40)、MSG\_WDATA(0x44)、OUT\_RDATA(0x48)、 TAGOUT(0x4C--58)。当前交付采用调用者写入的测试 key，具体规则见 §2.3.3.3。
