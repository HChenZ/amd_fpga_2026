以下步骤从空白环境开始，按"主机验证 → 仿真回归 → 构建比特流 → 上板"顺序执行。每一步都有可判定的通过标准，
失败时保留日志并停止，不跳到下一步。所有命令在仓库根目录执行。

| 项 | 版本或要求 |

| 固件工具链 | RV32 GCC（归档构建为 13.2.0，`rv32im_zicsr` / `ilp32`） |
